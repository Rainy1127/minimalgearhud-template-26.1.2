# Changelog

## 1.0.0

First release.

- Compact HUD widget: main hand, off hand and all four armor pieces with item icon, durability text and a thin color bar
- Pulsing low-durability warning: soft below 10%, urgent below 5% and always urgent when the item breaks on its next use
- Warning glows along the screen edges and highlights the affected row in the widget
- Approximate remaining uses (~N) for held items, aware of Unbreaking
- Small green + marker on items with Mending
- Smart visibility: show all items, only damaged ones, or only items that need attention
- Fully configurable: screen anchor, offsets, scale, background opacity, text format, color scheme
- Colorblind-friendly color scheme and a reduced-motion mode with a steady glow instead of pulsing
- Optional warning sound with volume and cooldown
- Key to show or hide the widget (default H, rebindable)
- In-game config screen (Mods -> Minimal Gear HUD -> Config), English and Russian translations
- Client-side only: nothing to install on servers
